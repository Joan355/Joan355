## 🚀 Proyectos públicos destacados

Estos repositorios públicos muestran implementaciones demostrables, pruebas técnicas y exploración de enfoques que complementan mi experiencia aplicada.

### [descargador_xm](https://github.com/Joan355/descargador_xm)
Herramienta en Python para consultar y descargar datos de XM (Sinergox/SiMEM), con filtros por catálogo y exportación a CSV para facilitar análisis y uso operativo.

**Tecnologías:** Python · Batchfile

### [GT-releases](https://github.com/Joan355/GT-releases)
Espacio de publicación de entregables y versiones para iniciativas de mejora operativa en contexto técnico.

**Enfoque:** versionado de entregables · mejora operativa

### [tftp-project](https://github.com/Joan355/tftp-project)
Implementación modular de transferencia de archivos basada en TFTP, con componentes de servidor, protocolo y pruebas para validar el comportamiento de la solución.

**Tecnologías:** Python · Redes · Protocolos de comunicación

### [P2P-intercom](https://github.com/Joan355/P2P-intercom)
Sistema de comunicación P2P sobre UDP con enrutamiento entre nodos, soporte de envío unicast/broadcast y manejo de saltos para propagar mensajes.

**Tecnologías:** Python · C++ · Sistemas distribuidos

### [rpc](https://github.com/Joan355/rpc)
Implementación de RPC sobre sockets TCP con serialización JSON, registro dinámico de métodos en servidor y cliente para invocación remota.

**Tecnología:** Python · Sistemas distribuidos

### [MPI](https://github.com/Joan355/MPI)
Implementación de multiplicación de matrices distribuida con MPI, usando reparto y recolección de bloques entre procesos para paralelizar el cálculo.

**Tecnologías:** C · Shell · Computación paralela

### [HPC](https://github.com/Joan355/HPC)
Experimentos de rendimiento para cómputo numérico en C, incluyendo medición de tiempos en operaciones de multiplicación de matrices.

**Tecnologías:** C · Python · Shell
